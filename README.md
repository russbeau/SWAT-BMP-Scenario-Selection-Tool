# SWAT_BMP_Scenario_Selection_Tool

## Overview

This repository contains a set of R scripts and a Shiny application for
generating, managing, and running SWAT+ watershed model scenarios of different
agricultural Best Management Practices (BMPs). The Shiny application allows users
to interact with the SWAT+ simulated outputs in a GUI.
- Generate unique combinations of farming BMP scenarios
- Modify SWAT+ input files to represent BMP scenarios
- Run the SWAT+ model to obtain hru-scale total nitrogen and total dissolved phosphorus runoff outcomes for each generated scenario
- Compare BMP Scenario water quality outcomes within a Shiny app (`BMP_Scenario_Tool/app.R`)

The BMP selection tool was designed to enable farmers to directly interact with a database of pre-simulated
hydrologic model outputs to compare predicted changes to TN and TDP export and crop yield between
user-defined BMP scenarios. When the user opens the online tool, they are first prompted to click through
a guided explanation about how to use the tool and what the different components do. They can then use 
drop down menus to select practices (shown in Table 1) for both a reference scenario and a 
comparison scenario. With each input selection, the tool automatically updates bar graphs that show the mean,
minimum, and maximum difference in TN and TDP (Comparison - Reference), the mean, minimum, and maximum percent
change in crop yield (Comparison vs. Reference), and the TN and TDP export of both scenarios individually (Fig. 7).
The difference bar graph displays green if the TN or TDP export of the comparison scenario is less than the export of
the reference scenario and red if the comparison scenario is greater. Similarly, the crop yield plot displays green
if crop yield increases under the comparison scenario and red if crop yield decreases. Additionally, the tool 
has a button to reset all inputs to their baseline, and a button to access the guided explanation at any point. 
A “More Information” tab at the top of the page contains links to external resources for users to access additional
information about any of the included BMPs.

## Requirements

- **Constructed and Calibrated SWAT+ 60.5.7 Model(s)**
- **R** (version 4.3.2 or later) 
- R packages: **stringr, data.table, shiny, dplyr, rintrojs, ggplot2, patchwork**
- **SWAT+ executable version 60.5.7 (64-bit)** 

## General Instructions

1. Construct SWAT+ models using QGIS and SWAT+ Editor.
2. Calibrate 5 "best" parameter sets using the CDF method
   (Ala-aho et al., 2017) and replace values in `CDF_Simulations.csv` with the
   resulting parameter value sets.
3. Copy the `TxtInOut` directory from your SWAT+ models into the
   `Watershed` directory, and ensure that `rev60.5.7_64rel.exe` is present
   there.
4. Create templates in the `SWAT_par_temps` directory by copying the
   appropriate files from `TxtInOut` and replacing text file values with
   character strings that match those seen in each template file example.
5. Create `hru_list.csv` by filtering for rows where column `lu_mgt` equals
   `agrr_lum` or `hay_lum`. Then use the resulting `name` column to extract
   matching HRU areas from the `hru.con` file in `TxtInOut`. The format should
   match that `Watershed/SWAT_par_temps/hru_list.csv`.
6. Run `FarmingScenarioRunner.R` for each watershed.
7. Run `FarmingScenariosMaster.R`.
8. Create `BMP_Scenario_Data.csv` by copying `FarmingScenariosMaster.csv`
   into the `BMP_Scenario_Tool` directory and deleting all columns except
   for the first nine and last nine.
9. Ensure that all syntax in your created `BMP_Scenario_Data.csv` match with
   the example file in this repository, or code may not run correctly.
10. Run `app.R`.
